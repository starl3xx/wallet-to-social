# CI gates

One row per check that lands on a PR, so a red can be triaged without
rediscovering which gates are deterministic and which are environmental. The
workflow headers remain the authority on _why_ each check exists; this is the
map of _what to do when one fails_.

Scheduled, not PR gates: `db-backup.yml` (daily), `snapshot-harvest.yml` and
`opensea-enrich.yml` (Sundays), `farcaster-sweep.yml` (the 2nd of each month).
`published-figures.yml` runs both ways: Mondays as the drift catcher, plus a
path-filtered PR trigger when published copy, `lib/public-figures.ts` or the
checker changes; `holder-fallback.yml` likewise lands on PRs touching its own
inputs.

`npm run preflight` is the local repro shortcut: it runs every gate above that
needs no database, no Chrome and no secrets (format, typecheck, palette,
design-language, contrast, og-palette, invariants) in one command.

Rules of thumb: a stale `.next/` can fail `typecheck` on generated route
types; `rm -rf .next` and re-run. `npm run build` typechecks as part of the build, and
`npx tsc --noEmit` is the faster standalone check (the tree currently
typechecks clean); after touching `scripts/check-invariants.ts` always run
the guard too; after editing any string under `app/`, run design-language
before pushing.
